# Пробный набор: цикл пройден, город — хутор

Это не настоящие данные Baudi, а пробные: весь первый цикл пройден командой записи на копии
(2026-11-20, 296 шагов), потом к городу дописан рост до «Хутора».
Нужен, чтобы посмотреть сайт в состоянии, до которого живые данные ещё не дошли:
конец цикла, итог, памятник, развитый город, поломки.

Запуск: `npm run dev:copy` — сайт на http://localhost:5174, «сегодня» для него — 06.01.2027
(файл `.env.copy` в корне). Чтобы увидеть долгий перерыв и поломки, поставь в `.env.copy.local`
`DATA_TODAY=2027-01-20`. Чего в наборе нет, берётся из живых данных: план цикла общий.

В журнале набора есть свои строки занятий (у 23 занятий из 33) и прогнозы — у всех недельных тестов и у 14 попыток на таймере: на них видны летопись города и карточка «Прогноз и факт».

Тесты на этом наборе: `DATA_ROOT=fixtures/closed-cycle npm test` — блоки «живые данные» пойдут по нему.
