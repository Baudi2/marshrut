# Правила для агентов

Все правила проекта, порядок записи занятий, тестов, стороннего развития и покупок — в `CLAUDE.md`. Состояние работы — в `docs/STATUS.md`, принятые решения — в `docs/DECISIONS.md`.

Коротко: менять данные только по словам Baudi, ничего производного в JSON не хранить, после правки данных запускать `npm test`.
